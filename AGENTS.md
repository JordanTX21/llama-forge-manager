# LlamaForge Agent Guide

## Quick Start

```powershell
python manager.py
```

Creates `venv/`, installs Python deps, auto-builds `ui/` on source changes, starts unified server on port 5170 (or `DEFAULT_PORT` from `.env`). Ctrl+C to stop.

## Architecture

- **Backend** (`api/`): FastAPI + Uvicorn. Routers: `hardware.py`, `huggingface.py`, `runner.py`, `commands.py`, `recommend.py`, `agents.py`.
- **Frontend** (`ui/`): Vue 3 + Composition API `<script setup>` + TypeScript + Vite + TailwindCSS v4 (via `@tailwindcss/vite`). Alias `@` → `ui/src/`.
- **Orchestration**: PowerShell (`.ps1`) on Windows, Bash (`.sh`) on macOS/Linux. Wrappers around `llama-server.exe` and `llama-swap`.
- **User data isolation**: All models, configs, commands, and binaries live in `~/.llama-forge/` (resolved by `api/paths.py`). Supports global installations.
- **Three routes**: `/` (Dashboard), `/models` (Model Hub), `/settings` (Inference Config).

## Commands

| Task | Command |
|---|---|
| Start all services | `python manager.py` |
| Backend only | `uvicorn api.main:app --host 127.0.0.1 --port 5170` (from venv) |
| Frontend only | `npm run dev` (inside `ui/`) |
| Frontend build | `npm run build` (runs `vue-tsc -b && vite build`) |
| Standalone (PyInstaller) | `python run.py` |
| API docs | `http://localhost:5170/docs` |

## Key Constraints

- **Cross-platform**: Windows uses `.ps1` + `winget`; macOS/Linux uses `.sh` + `brew`. Auto-installs `llama.cpp` / `llama-swap` if missing.
- **`llama-server` path**: resolved from `.env` (`LLAMA_BIN_DIR`, `LLAMA_SERVER_EXE`) or falls back to PATH / `bin/`.
- **`config.yaml`**: auto-generated by `api/commands.py` (POST `/api/commands/`). Gitignored — do not hand-edit.
- **`commands/*.ps1` / `commands/*.sh`**: auto-generated from Settings UI. Each wraps `scripts/run_model.ps1` / `scripts/run_model.sh` with parsed args.
- **Models directory**: `~/.llama-forge/models/<Author>/<Repo>/<filename>.gguf`. Scanned by `api/huggingface.py`.
- **Standalone mode** (`run.py`): reads `DEFAULT_PORT` from `~/.llama-forge/.env`; copies `.env.example` → `~/.llama-forge/.env` if missing.

## Environment Variables

| Key | Default | Description |
|---|---|---|
| `LLAMA_BIN_DIR` | (empty) | Path to llama.cpp binary directory |
| `LLAMA_SERVER_EXE` | `llama-server.exe` | Executable name |
| `DEFAULT_HOST` | `127.0.0.1` | Bind host |
| `DEFAULT_PORT` | `5170` | Unified server port |
| `DEFAULT_MAX_CONTEXT_TOKENS` | `128000` | Max context for agents |
| `DEFAULT_MAX_OUTPUT_TOKENS` | `65536` | Max output for agents |
| `HF_TOKEN` | (empty) | HuggingFace token for private models |

Copy `.env.example` to `.env` to configure.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/status` | Health check |
| GET | `/api/hardware/` | CPU/RAM/GPU metrics (`nvidia-smi` + `psutil`) |
| POST | `/api/huggingface/download` | Download GGUF via HF CLI |
| GET | `/api/huggingface/local` | List downloaded models |
| GET | `/api/commands/` | List command configs (parses `.ps1`/`.sh`) |
| POST | `/api/commands/` | Save command config (writes script + updates `config.yaml`) |
| POST | `/api/runner/start` | Start a model directly |
| POST | `/api/runner/swap` | Start llama-swap |
| POST | `/api/recommend/` | AI-based inference config recommendations |
| GET | `/api/agents/status` | Check installed agents (Opencode, QwenCode) |
| POST | `/api/agents/configure` | Configure agent model endpoint |

## Frontend Notes

- Vue Router uses `createWebHistory` (not hash mode).
- Components lazy-loaded for `/models` and `/settings`; Dashboard is eager.
- TailwindCSS v4 via Vite plugin — no `tailwind.config.js`. Styles as utility classes only.
- API client (`ui/src/services/api.service.ts`) hardcodes `http://localhost:5170/api`. Change for non-local dev.
- Pinia stores for state; Vue I18n for i18n.

## Generated / Excluded Files

Gitignored: `bin/`, `models/`, `venv/`, `.env`, `config.yaml`, `__pycache__/`, `ui/dist/`.
Not gitignored but auto-generated: `commands/` directory. Do not commit model files, venv, generated configs, or build artifacts.
