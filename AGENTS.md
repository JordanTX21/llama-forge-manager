# LlamaForge Agent Guide

## Quick Start

```powershell
.\start-manager.ps1
```

One command: creates `venv/`, installs Python deps, runs `npm install` in `ui/`, starts FastAPI (port 8000) and Vite (port 5173). Press any key to stop both.

## Architecture

- **Backend** (`api/`): FastAPI + Uvicorn. Routers split into `hardware.py`, `huggingface.py`, `runner.py`, `commands.py`.
- **Frontend** (`ui/`): Vue 3 + Composition API + TypeScript + Vite + TailwindCSS v4 (via `@tailwindcss/vite`). Alias `@` → `ui/src/`.
- **Orchestration** (`scripts/`, `commands/`): PowerShell scripts wrapping `llama-server.exe` and `llama-swap`.
- **Three routes**: `/` (Dashboard), `/models` (Model Hub), `/settings` (Inference Config).

## Commands

| Task | Command |
|------|---------|
| Start all services | `.\start-manager.ps1` |
| Backend only | `uvicorn api.main:app --host 127.0.0.1 --port 8000` (from venv) |
| Frontend only | `npm run dev` (inside `ui/`) |
| Frontend build | `npm run build` (runs `vue-tsc -b && vite build`) |
| API docs | `http://localhost:8000/docs` |

## Key Constraints

- **Windows-only**: all orchestration is PowerShell. Scripts use `-ExecutionPolicy Bypass`.
- **`llama-server.exe` path**: resolved from `.env` (`LLAMA_BIN_DIR`, `LLAMA_SERVER_EXE`) or defaults to `bin\llama-b9037-bin-win-cuda-13.1-x64\llama-server.exe`.
- **`config.yaml`** is auto-generated by `api/commands.py` (POST `/api/commands/`). It's gitignored — do not hand-edit.
- **`commands/*.ps1`** files are auto-generated from the Settings UI. Each wraps `scripts/run_model.ps1` with parsed args.
- **Models directory**: `models/<Author>/<Repo>/<filename>.gguf`. Scanned by `api/huggingface.py`.
- **`start-swap.ps1`**: launches `llama-swap --config config.yaml --listen 127.0.0.1:8080`. Requires `llama-swap` on PATH.

## Env Loading

`scripts/run_model.ps1` reads `.env` at project root and exports vars to the process environment. Keys: `LLAMA_BIN_DIR`, `LLAMA_SERVER_EXE`, `DEFAULT_CTX_SIZE`, `DEFAULT_NGL`, `DEFAULT_HOST`, `HF_TOKEN`. Copy `.env.example` to `.env` to configure.

## API Endpoints

- `GET  /api/status` — health check
- `GET  /api/hardware/` — CPU/RAM/GPU metrics (uses `nvidia-smi` + `psutil`)
- `POST /api/huggingface/download` — download GGUF via PowerShell script
- `GET  /api/huggingface/local` — list downloaded models
- `GET  /api/commands/` — list all command configs (parses `.ps1` files)
- `POST /api/commands/` — save a command config (writes `.ps1` + updates `config.yaml`)
- `POST /api/runner/start` — start a model directly
- `POST /api/runner/swap` — start llama-swap

## Frontend Notes

- Vue Router uses `createWebHistory` (not hash mode).
- Components are lazy-loaded for `/models` and `/settings`; Dashboard is eager.
- TailwindCSS v4 via Vite plugin — no `tailwind.config.js`. Styles are written as utility classes directly.
- API client (`ui/src/services/api.service.ts`) hardcodes `http://localhost:8000/api`. Change for non-local dev.

## Generated / Excluded Files

Gitignored: `bin/`, `models/`, `venv/`, `.env`, `config.yaml`, `commands/` (not gitignored but auto-generated). Do not commit model files, venv, or generated configs.
